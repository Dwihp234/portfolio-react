# Supply Chain Management Gallery Images

This folder contains images for the Supply Chain Management gallery section.

## Expected Images:
- scm-dashboard.jpg - Supply Chain Dashboard screenshot
- logistics-network.jpg - Global logistics network visualization  
- inventory-system.jpg - Inventory management system interface
- transportation.jpg - Transportation optimization charts
- procurement.jpg - Procurement process flowchart

## Image Requirements:
- Format: JPG, PNG
- Size: Recommended 800x600 or 16:9 aspect ratio
- Quality: High resolution for portfolio display

## Usage:
These images will be displayed in the Professional Gallery section under the "Supply Chain Management" filter.
