# Repair & Maintenance Department Analytics

This folder contains analytics dashboards and reports for the Repair & Maintenance department.

## Contents:
- maintenance-dashboard.jpg - Main maintenance overview dashboard
- equipment-analysis.jpg - Equipment performance analysis
- failure-prediction.jpg - Predictive maintenance models
- efficiency-report.jpg - Department efficiency reports

## Technologies Used:
- R Programming
- Power BI
- SQL Server
- Python (for ML models)

## Key Metrics Tracked:
- Equipment uptime
- Maintenance costs
- Failure rates
- Work order completion
- Spare parts inventory
